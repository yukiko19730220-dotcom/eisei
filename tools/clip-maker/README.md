# ランチ配信 切り抜きツール

YouTubeでライブ配信した「ランチ営業の定点動画（約2時間）」から、
**YouTubeショート／インスタグラムリール用の縦動画（9:16）** を自動で切り抜きます。

音の盛り上がり（会話・笑い声・調理音）と画面の動き（お客さんの出入り・配膳）を
1秒きざみで解析して、**にぎわっている場面**を自動で選びます。

---

## 準備（MacBook・最初の1回だけ）

1. `command + スペース` で Spotlight を開き、「**ターミナル**」と入力して起動
2. 下の1行をコピーして貼り付け、`return` キー

```
pip3 install imageio-ffmpeg
```

これで動画処理エンジン（ffmpeg）が入ります。以降この作業は不要です。

---

## 使い方

### 1. 動画をMacに保存する

Googleドライブ（またはGoogleフォト）から、配信の動画を Mac の「**ダウンロード**」フォルダに保存します。

### 2. ターミナルで実行する

ターミナルに次のように入力します。**動画ファイルはドラッグ＆ドロップ**すると
パスが自動で入るので、手打ちする必要はありません。

```
python3 ~/Downloads/clip.py 
```

↑ここまで打ったら、**動画ファイルをターミナルの窓にドラッグ**して `return`。

終わると「**ダウンロード**」の中に `clips` フォルダができ、縦動画が入っています。
`clips.csv` に「何本目が元動画の何分何秒か」の一覧も出ます。

---

## よく使う調整

| やりたいこと | 付け足すもの |
|---|---|
| 本数を10本にする | `--count 10` |
| 1本を60秒にする | `--length 60` |
| 厨房側（画面の左）を中心に切る | `--crop-x 0.25` |
| 客席側（画面の右）を中心に切る | `--crop-x 0.75` |
| 店内全体を写したい（上下ぼかし） | `--style blur` |
| 書き出さず、候補の時刻だけ見たい | `--dry-run` |
| 書き出しを速くする（スマホ推奨） | `--preset veryfast` |

書き方の例（10本・各45秒・少し左寄りで切る）:

```
python3 ~/Downloads/clip.py ~/Downloads/配信.mp4 --count 10 --length 45 --crop-x 0.4
```

---

## 2つの切り抜きスタイル

- **`crop`（既定）** … 画面の一部を切り出して縦画面いっぱいに使います。
  被写体が大きく映るのでショート／リール向き。`--crop-x` で左右位置を決めます。
- **`blur`** … 元の映像を丸ごと入れて、上下の余白をぼかした背景で埋めます。
  店内全体の雰囲気を見せたいときに。

## Androidスマホで使う場合

パソコンを開かなくても、**Termux** というアプリを使えばスマホだけで同じことができます。

### 準備（最初の1回だけ）

1. **F-Droid**（ https://f-droid.org ）から **Termux** をインストール
   ※Google Play版のTermuxは更新が止まっていて動きません。必ずF-Droid版を使ってください
2. Termuxを開いて、次を順に実行

```
pkg update
pkg install python ffmpeg
termux-setup-storage
```

`termux-setup-storage` を実行すると、スマホから「アクセスを許可しますか」と聞かれるので**許可**します。

### 使い方

配信動画をスマホの「ダウンロード」フォルダに保存してから、Termuxで:

```
cd ~/storage/shared/Download
python clip.py 配信.mp4 --preset veryfast
```

書き出された縦動画は同じフォルダの `clips` に入り、
ギャラリーアプリからそのままYouTubeやインスタに投稿できます。

**スマホでは必ず `--preset veryfast` を付けてください。** 付けないと書き出しに数倍の時間がかかります。

### スマホでの目安

2時間の動画で、解析に **5〜15分**、書き出しは1本あたり **1〜3分**ほど。
本体が熱くなるので、充電しながら実行するのをおすすめします。

## もっと手軽に済ませたい場合（アプリだけ）

自動検出はできませんが、**YouTubeアプリ**（Studioではなく、ふだん視聴に使うほう）に
既存動画からショートを作る機能があります。**スマホ専用**でパソコンでは使えません。

1. YouTubeアプリで自分が配信した動画を開く
2. 動画の下のボタン列から **［共有］（右向きの矢印）** をタップ
3. メニュー内の **［リミックス］** → **［ショート動画として編集］** をタップ
4. 使いたい範囲を選ぶ（最長60秒）
5. ［次へ］でテキストやフィルタを足して投稿

> **［リミックス］が見当たらないとき**
> 以前は動画の下に直接並んでいましたが、アプリの更新で **［共有］の中**に
> 移動しました。無ければ一番右の ［•••］ も確認してください。

> **5秒までしか選べないとき**
> ［リミックス］のあとで「切り抜き」を選ぶと **1〜5秒** しか取れません
> （曲の一部をサンプリングする別機能です）。一つ戻って
> **［ショート動画として編集］** を選び直してください。

設定不要でその場で作れます。ただし**自分で見どころを探す必要**があり、
**最長60秒**まで、書き出し先はYouTubeショートのみ。
またこの方法で作ったショートには**YouTubeの音楽ライブラリの曲は使えません**。

### 参考: YouTubeの自動ハイライト

YouTubeにはライブ配信からハイライトを自動抽出してショートにする機能もありますが、
**縦向き配信であること**と**YouTubeモバイルアプリからの配信であること**が条件のため
（ほかに配信の長さが10分〜12時間）、横向きの定点配信は対象外です。

インスタのリールにも同じものを出したい場合は、
**CapCut**アプリに動画を読み込んで9:16で書き出す形になります。

「自動で見どころを探してほしい」ならTermux、
「1〜2本だけ手早く作りたい」ならアプリ、と使い分けるのがよいと思います。

---

## 目安の処理時間

2時間の動画の場合、MacBook で

- 解析（見どころ探し）… **1〜3分**
- 書き出し … **1本あたり10〜30秒**

---

## 投稿の目安

| | 長さ | サイズ |
|---|---|---|
| YouTube ショート | 60秒以内が無難（最長3分） | 1080×1920 |
| インスタグラム リール | 15〜60秒が伸びやすい | 1080×1920 |

このツールの出力は 1080×1920 / H.264 / AAC で、どちらにもそのまま投稿できます。

---

## うまくいかないとき

- `python3: command not found` → Mac に Python が入っていません。
  ターミナルで `xcode-select --install` を実行してください。
- `ffmpeg が見つかりません` → 上の「準備」の `pip3 install imageio-ffmpeg` をやり直してください。
- 見どころがイマイチ → `--dry-run` で候補時刻だけ確認し、`--length` や `--count` を変えて調整します。
