# ランチ配信 切り抜きツール

YouTubeでライブ配信した「ランチ営業の定点動画（約2時間）」から、
**YouTubeショート／インスタグラムリール用の縦動画（9:16）** を自動で切り抜きます。

音の盛り上がり（会話・笑い声・調理音）と画面の動き（お客さんの出入り・配膳）を
1秒きざみで解析して、**にぎわっている場面**を自動で選びます。

---

## 準備（MacBook・最初の1回だけ）

1. `command + スペース` で Spotlight を開き、「**ターミナル**」と入力して起動
2. 下の1行をコピーして貼り付け、`return` キー

```
pip3 install imageio-ffmpeg
```

これで動画処理エンジン（ffmpeg）が入ります。以降この作業は不要です。

---

## 使い方

### 1. 動画をMacに保存する

Googleドライブ（またはGoogleフォト）から、配信の動画を Mac の「**ダウンロード**」フォルダに保存します。

### 2. ターミナルで実行する

ターミナルに次のように入力します。**動画ファイルはドラッグ＆ドロップ**すると
パスが自動で入るので、手打ちする必要はありません。

```
python3 ~/Downloads/clip.py 
```

↑ここまで打ったら、**動画ファイルをターミナルの窓にドラッグ**して `return`。

終わると「**ダウンロード**」の中に `clips` フォルダができ、縦動画が入っています。
`clips.csv` に「何本目が元動画の何分何秒か」の一覧も出ます。

---

## よく使う調整

| やりたいこと | 付け足すもの |
|---|---|
| 本数を10本にする | `--count 10` |
| 1本を60秒にする | `--length 60` |
| 厨房側（画面の左）を中心に切る | `--crop-x 0.25` |
| 客席側（画面の右）を中心に切る | `--crop-x 0.75` |
| 店内全体を写したい（上下ぼかし） | `--style blur` |
| 書き出さず、候補の時刻だけ見たい | `--dry-run` |

書き方の例（10本・各45秒・少し左寄りで切る）:

```
python3 ~/Downloads/clip.py ~/Downloads/配信.mp4 --count 10 --length 45 --crop-x 0.4
```

---

## 2つの切り抜きスタイル

- **`crop`（既定）** … 画面の一部を切り出して縦画面いっぱいに使います。
  被写体が大きく映るのでショート／リール向き。`--crop-x` で左右位置を決めます。
- **`blur`** … 元の映像を丸ごと入れて、上下の余白をぼかした背景で埋めます。
  店内全体の雰囲気を見せたいときに。

---

## 目安の処理時間

2時間の動画の場合、MacBook で

- 解析（見どころ探し）… **1〜3分**
- 書き出し … **1本あたり10〜30秒**

---

## 投稿の目安

| | 長さ | サイズ |
|---|---|---|
| YouTube ショート | 60秒以内が無難（最長3分） | 1080×1920 |
| インスタグラム リール | 15〜60秒が伸びやすい | 1080×1920 |

このツールの出力は 1080×1920 / H.264 / AAC で、どちらにもそのまま投稿できます。

---

## うまくいかないとき

- `python3: command not found` → Mac に Python が入っていません。
  ターミナルで `xcode-select --install` を実行してください。
- `ffmpeg が見つかりません` → 上の「準備」の `pip3 install imageio-ffmpeg` をやり直してください。
- 見どころがイマイチ → `--dry-run` で候補時刻だけ確認し、`--length` や `--count` を変えて調整します。
